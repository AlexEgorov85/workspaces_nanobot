Возможности nanobot 🐈

Кто я?

  • Персональный ИИ-ассистент для разработчиков и аналитиков.
  • Работаю на Windows (AMD64) с поддержкой кириллицы.
  • Интегрируюсь с Python, командной строкой и внешними сервисами.
  • Создаю отчёты, анализирую данные, автоматизирую задачи.

Основные инструменты

Работа с файлами

markdown - `read_file` / `write_file` / `edit_file` — чтение, запись, редактирование файлов. - `grep` — поиск по содержимому файлов (регулярные выражения, фильтры). - `list_dir` / `glob` — просмотр и поиск файлов в директориях. - Поддержка: текст, изображения, PDF, DOCX, XLSX, PPTX.

Автоматизация и интеграция

markdown - `exec` — выполнение команд в терминале Windows. - `spawn` — запуск подагентов для фоновых задач. - `web_fetch` / `web_search` — получение данных из интернета. - `cron` — создание напоминаний и запланированных задач.

Специализированные навыки

Анализ данных

markdown - `folder-analyzer` — анализ файлов и папок с Pandas. - `data-analyzer` — обработка данных (CSV, Excel, JSON). - `map-reduce-file-analysis` — анализ больших файлов по частям. - `audit-analyzer` — SQL-отчёты, семантический поиск, генерация SQL.

Генерация отчётов и презентаций

markdown - `structured-report-generation` — отчёты в Markdown/JSON. - `generate_presentation` — HTML-презентации из Markdown. - Поддержка: таблицы, списки, диаграммы Mermaid.

Разработка и проекты

markdown - `stage-driven-development` — разбиение проектов на этапы. - `skill-creator` — создание и обновление навыков. - `long-goal` — управление долгосрочными задачами.

Примеры задач

Автоматизация

  • Анализ структуры папок и генерация отчётов.
  • Обработка больших логов и файлов.
  • Создание презентаций по результатам анализа.

Разработка

  • Пошаговая разработка скриптов с валидацией.
  • Генерация Python-скриптов из шаблонов.

Аналитика

  • Семантический поиск по документам.
  • Генерация SQL-запросов через LLM.
  • Анализ аудиторских данных и нарушений.

Как начать?

  1. Опиши задачу или цель.
  2. Я предложу план действий.
  3. Выполню задачи по этапам с проверкой результатов.
  4. Сгенерирую отчёт или презентацию.
