# Vector indexes (audit_analyzer)

FAISS-индексы, доступные навыку `audit_analyzer`. Загружается по необходимости,
когда агент выбирает `index_name` для `vector_search`.

Эти знания — **домен skill'а**. Tool `vector_search` не знает про эти имена;
он получает `index_name` как параметр от вызывающей стороны.

## `audits_index`

| поле | значение |
|---|---|
| **Источник** | `oarb.audits` |
| **embed-колонка** | `title` (заголовок проверки) |
| **Когда использовать** | поиск проверок по смыслу заголовка: «проверки по пожарной безопасности», «бухгалтерские ревизии» |
| **score-интерпретация** | `0.6+` — высокая схожесть, `0.4–0.6` — умеренная, `<0.4` — низкая |
| **default для tool** | да (используется по умолчанию в CLI при `--mode vector` без `--index-name`) |

## `violations_index`

| поле | значение |
|---|---|
| **Источник** | `oarb.violations` |
| **embed-колонка** | `description` (описание нарушения) |
| **Когда использовать** | поиск нарушений по смыслу: «нарушения пожарной безопасности», «финансовые нарушения» |
| **score-интерпретация** | `0.65+` — высокая, `0.5–0.65` — умеренная |
| **default для tool** | нет |

## `audit_reports_index`

| поле | значение |
|---|---|
| **Источник** | `oarb.audit_reports` |
| **embed-колонка** | `title`, `full_text` |
| **Когда использовать** | поиск по отчётам целиком: «отчёты с выводами о неэффективности» |
| **score-интерпретация** | `0.55+` — высокая, `0.4–0.55` — умеренная |
| **default для tool** | нет |

## Конвенции

- `index_name` — строковый идентификатор. Метаданные индексов (источник,
  embed-колонки, signature) живут в `public.agent_vector_index_config`.
  Сериализованный FAISS BYTEA — в `public.agent_vector_index_store`.
- Все три индекса зарегистрированы в `public.agent_vector_index_config` через
  `sql/audit_analyzer/seed_default_indexes.sql`.
- Параметр `top_k` tool'а `vector_search` ограничен `max_top_k` из конфига
  (`gateway.vector_search.max_top_k`, по умолчанию 50).
- Параметр `threshold` tool'а ограничен `[0.0, 1.0]`. Значение по умолчанию —
  `gateway.vector_search.default_threshold` (0.0 — без фильтра).

## Когда НЕ использовать vector_search

- Числовой анализ / агрегация / группировка → `duckdb_query`.
- Точный поиск по известному `id` → `duckdb_query WHERE id = ?`.
- Сложные фильтры по нескольким колонкам → `duckdb_query`.
