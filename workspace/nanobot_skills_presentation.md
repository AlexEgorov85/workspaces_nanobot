# nanobot 🐈 — Обзор возможностей

---

## Кто я?
- Персональный ИИ-ассистент для разработчиков и аналитиков.
- Работаю на Windows (AMD64) с поддержкой кириллицы.
- Интегрируюсь с Python, командной строкой и внешними сервисами.
- Создаю отчёты, анализирую данные, автоматизирую задачи.

---

## Основные инструменты

### Работа с файлами
```markdown
- `read_file` / `write_file` / `edit_file` — чтение, запись, редактирование файлов.
- `grep` — поиск по содержимому файлов (регулярные выражения, фильтры).
- `list_dir` / `glob` — просмотр и поиск файлов в директориях.
- Поддержка: текст, изображения, PDF, DOCX, XLSX, PPTX.
```

---

### Автоматизация и интеграция
```markdown
- `exec` — выполнение команд в терминале Windows.
- `spawn` — запуск подагентов для фоновых задач.
- `web_fetch` / `web_search` — получение данных из интернета.
- `cron` — создание напоминаний и запланированных задач.
```

## Специализированные навыки

### Анализ данных
```markdown
- `folder-analyzer` — анализ файлов и папок с Pandas.
- `data-analyzer` — обработка данных (CSV, Excel, JSON).
- `map-reduce-file-analysis` — анализ больших файлов по частям.
- `db_analyzer` — SQL-отчёты, семантический поиск, генерация SQL.
```
