# Audit Analyzer

Комплексный навык для анализа аудиторских проверок с тремя режимами работы: заготовленные скрипты, генерация SQL и векторный поиск.

## Возможности

### 🎯 **Заготовленные скрипты с параметрами**
- 6 предустановленных аналитических скриптов
- Автоматическое извлечение параметров из запроса
- Высокая скорость выполнения

### 🔍 **Векторный поиск по документам**
- **Только поиск**: Навык ищет по готовому индексу (`audit_index`).
- Интеграция с навыком `vector-search` для семантического поиска.
- Поиск по содержанию нарушений, рекомендаций и описаний проверок.
- Поддержка нескольких векторных баз данных.
- Поддержка двух режимов поиска:
  - Поиск по схожести: возвращает определенное количество результатов с наибольшим значением похожести.
  - Поиск по порогу: возвращает все результаты, которые по схожести выше указанного порога.

### Примеры использования:
```python
# Поиск по схожести
results = await api.search_audit_documents(
    query="финансовые нарушения",
    search_mode="top_k",
    db_name="audit_db"
)

# Поиск по порогу
results = await api.search_audit_documents(
    query="кадровые вопросы",
    search_mode="threshold",
    threshold=0.8,
    db_name="audit_db"
)
```

### 🤖 **Генерация SQL**
- Автоматическая генерация запросов через LLM
- Валидация безопасности
- Fallback для сложных запросов

## 📋 Доступные скрипты

| Скрипт | Описание | Ключевые слова |
|--------|----------|----------------|
| `analytics_by_year_month` | Аналитика проверок по годам/месяцам | год, месяц, аналитика, статистика |
| `violations_by_type` | Анализ нарушений по типам | нарушение, тип, категория |
| `top_audited_objects` | Топ проверяемых объектов | топ, объект, рейтинг |
| `audit_effectiveness` | Эффективность проверок | эффективность, результат, нарушение |
| `audit_dynamics` | Динамика по периодам | динамика, период, тренд |
| `audit_types_stats` | Статистика по типам проверок | тип, проверка, классификация |

## 🚀 Использование

### Базовое использование
```python
from audit_analyzer import AuditAnalyzerAPI

api = AuditAnalyzerAPI()
result = await api.analyze_query("покажи статистику проверок за 2024 год", auto_execute=True)
```

### Примеры запросов

**Заготовленные скрипты:**
- "покажи аналитику по годам и месяцам"
- "топ 10 объектов по количеству проверок"
- "статистика нарушений по типам"

**Векторный поиск (только поиск по готовому индексу):**
- "финансовые нарушения в университетах"
- "кадровые вопросы при проверках"
- "налоговые нарушения за последний год"

**Генерация SQL:**
- "найди проверки с наибольшим количеством нарушений"
- "покажи объекты с повторными нарушениями"
- "сравни эффективность разных типов проверок"

## 🔄 Логика работы

1. **Поиск заготовленного скрипта** - по ключевым словам
2. **Векторный поиск** - если скрипт не найден
3. **Генерация SQL** - fallback для сложных запросов
