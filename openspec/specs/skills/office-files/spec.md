# Office Files Skill

## Назначение

Office Files Skill обеспечивает обработку офисных документов (Word, Excel, PowerPoint, PDF), извлечение текста и метаданных, анализ содержимого и интеграцию с другими Skills для дальнейшей обработки.

## Ответственность

- Чтение файлов различных офисных форматов
- Извлечение текста из документов
- Извлечение метаданных (автор, дата создания, версия)
- Обработка таблиц Excel
- Обработка презентаций PowerPoint
- Поддержка PDF документов
- Валидация формата и целостности файлов

## Граница

### Владеет
- Парсерами офисных форматов
- Логикой извлечения текста и метаданных
- Валидацией структуры файлов
- Конвертацией в единый внутренний формат представления

### Не владеет
- Бизнес-логикой анализа содержимого (делегирует другим Skills)
- Хранением оригиналов файлов
- Редактированием файлов (только чтение)
- Отображением файлов пользователю (делегирует UI)

### Требования

#### Требование: Поддержка форматов

**Сценарий: Обработка файла известного формата**
- **КОГДА** файл имеет поддерживаемое расширение
- **ТОГДА** применяется соответствующий парсер
- **И** извлекается текст и метаданные
- **И** результат возвращается в стандартизированном формате

Поддерживаемые форматы:
- `.doc`, `.docx` — Microsoft Word
- `.xls`, `.xlsx` — Microsoft Excel
- `.ppt`, `.pptx` — Microsoft PowerPoint
- `.pdf` — PDF documents
- `.odt`, `.ods`, `.odp` — OpenDocument formats
- `.txt`, `.rtf` — Text files

#### Требование: Извлечение текста

**Сценарий: Получение текстового содержимого**
- **КОГДА** требуется текст из документа
- **ТОГДА** вызывается `extract_text()` с путём к файлу
- **И** текст извлекается с сохранением структуры (абзацы, заголовки)
- **И** возвращается с информацией о кодировке и языке

#### Требование: Извлечение таблиц Excel

**Сценарий: Обработка электронных таблиц**
- **КОГДА** файл содержит таблицы Excel
- **ТОГДА** вызывается `extract_tables()` с опциональным именем листа
- **И** каждая таблица извлекается как структурированные данные
- **И** сохраняются типы данных ячеек (число, дата, текст, формула)

#### Требование: Извлечение метаданных

**Сценарий: Получение информации о файле**
- **КОГДА** требуются метаданные файла
- **ТОГДА** вызывается `extract_metadata()` с путём к файлу
- **И** извлекаются: автор, дата создания, изменения, версия
- **И** для Excel — информация о листах, для Word — количество страниц

#### Требование: Валидация файла

**Сценарий: Проверка целостности файла**
- **КОГДА** файл получен от пользователя
- **ТОГДА** вызывается `validate_file()` для проверки
- **И** проверяется соответствие формата расширению
- **И** проверяется отсутствие повреждений структуры
- **И** проверяется размер в пределах лимита

### Запрещённое поведение

Office Files Skill НЕ ДОЛЖЕН:
- Модифицировать оригинальные файлы
- Выполнять макросы из документов (security risk)
- Раскрывать содержимое файлов в логах
- Пропускать файлы с повреждённой структурой
- Обрабатывать файлы превышающие лимит размера
- Игнорировать ограничения на типы файлов

## Зависимости

### Может зависеть от
- SubprocessManager для внешних конвертеров
- CacheProvider для кэширования результатов парсинга

## Жизненный цикл

1. **Инициализация**: Загрузка парсеров, конфигурации лимитов
2. **Приём файла**: Получение пути к файлу или binary data
3. **Валидация**: Проверка формата, размера, целостности
4. **Обработка**: Извлечение текста, метаданных, таблиц
5. **Возврат результата**: Структурированные данные
6. **Очистка**: Удаление временных файлов (если применимо)

## Инварианты

- Файл валидируется перед обработкой
- Максимальный размер файла не превышается
- Временные файлы удаляются после обработки
- Макросы никогда не выполняются
- Результат всегда включает путь к исходному файлу

## Поведение при ошибке

- Неподдерживаемый формат → UnsupportedFormatError
- Превышение размера → FileTooLargeError
- Повреждённый файл → CorruptedFileError
- Ошибка парсинга → ParsingError с деталями
- Отсутствие доступа → FileAccessError
