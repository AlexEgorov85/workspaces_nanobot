# Транскрипция

## Назначение

Сервис транскрипции обеспечивает преобразование аудио в текст с использованием внешних моделей (Whisper и другие), предоставляя единый интерфейс для работы с различными транскриберами через управление подпроцессами.

## Ответственность

- Приём аудиофайлов различных форматов
- Выбор транскрибера на основе конфигурации
- Запуск процесса транскрипции через SubprocessManager
- Обработка результатов транскрипции
- Кэширование результатов для повторяющихся запросов
- Поддержка потоковой транскрипции (опционально)

## Граница

### Владеет
- Конфигурацией доступных транскриберов
- Логикой выбора транскрибера
- Кэшем результатов транскрипции
- Форматом выходных данных (текст + метаданные)

### Не владеет
- Реализацией моделей транскрипции (внешние процессы)
- Управлением процессами (делегирует SubprocessManager)
- Хранением аудиофайлов (временные файлы удаляются)
- Распознаванием языка (делегирует транскриберу)

## Контракт

### Публичный интерфейс

```python
class TranscriptionService:
    def transcribe(
        self,
        audio_path: str,
        language: Optional[str] = None,
        model: Optional[str] = None,
        options: Optional[Dict] = None
    ) -> TranscriptionResult
    
    async def transcribe_async(
        self,
        audio_path: str,
        language: Optional[str] = None,
        model: Optional[str] = None,
        options: Optional[Dict] = None
    ) -> TranscriptionResult
    
    def get_supported_models(self) -> List[str]
    def get_supported_languages(self) -> List[str]
    def clear_cache(self, audio_hash: Optional[str] = None) -> None
```

### Требования

#### Требование: Транскрипция файла

**Сценарий: Преобразование аудио в текст**
- **КОГДА** требуется транскрибировать аудиофайл
- **ТОГДА** вызывается `transcribe()` с путём к файлу
- **И** вычисляется хэш файла для кэша
- **И** при наличии в кэше возвращается кэшированный результат
- **И** иначе запускается процесс транскрипции
- **И** результат сохраняется в кэш и возвращается

#### Требование: Выбор модели

**Сценарий: Использование конкретной модели**
- **КОГДА** модель не указана явно
- **ТОГДА** используется модель по умолчанию из конфигурации
- **И** при указании модели проверяется её поддержка
- **И** неподдерживаемая модель вызывает исключение

#### Требование: Определение языка

**Сценарий: Автоматическое определение языка**
- **КОГДА** язык не указан
- **ТОГДА** транскрибер определяет язык автоматически
- **И** определённый язык возвращается в метаданных результата

#### Требование: Асинхронная транскрипция

**Сценарий: Неблокирующая транскрипция**
- **КОГДА** требуется транскрипция без блокировки
- **ТОГДА** вызывается `transcribe_async()`
- **И** задача выполняется в background
- **И** возвращается awaitable результат

### Запрещённое поведение

Transcription Service НЕ ДОЛЖЕН:
- Хранить аудиофайлы после транскрипции
- Возвращать результат без текста (пустой текст — валидный результат)
- Игнорировать лимиты времени транскрипции
- Превышать лимиты памяти при обработке больших файлов
- Кэшировать результаты с ошибками

## Зависимости

### Может зависеть от
- SubprocessManager для запуска транскриберов
- CacheProvider для кэширования результатов
- ConfigService для конфигурации моделей
- Logger для логирования событий

### Не должен зависеть от
- Конкретных реализаций транскриберов (абстрагирован)
- Бизнес-логики использования транскрипции
- Прямых вызовов внешних API

## Конфигурация

```yaml
transcription:
  enabled: true
  default_model: "whisper-medium"
  default_language: null  # auto-detect
  timeout_sec: 600.0
  max_file_size_mb: 100
  cache_enabled: true
  cache_ttl_hours: 24

    - "whisper-tiny"

    - "whisper-large"
  supported_formats:
    - "wav"
    - "mp3"
    - "flac"
    - "ogg"
    - "m4a"
  working_dir: "/tmp/nanobot_transcription"
```

## Жизненный цикл

1. **Инициализация**: Загрузка конфигурации, проверка доступности транскриберов
2. **Приём запросов**: Транскрипция аудио по запросу
3. **Кэширование**: Сохранение результатов для повторного использования
4. **Очистка**: Удаление старых записей кэша по TTL
5. **Завершение**: Очистка временных файлов

## Инварианты

- Результат транскрипции всегда содержит текст (может быть пустым)
- Кэш не превышает заданный размер
- Временные файлы удаляются после обработки
- Одна транскрипция файла выполняется в один момент времени (deduplication)

## Поведение при ошибке

- Ошибка транскрибера → исключение с деталями ошибки
- Таймаут транскрипции → исключение TimeoutError
- Неподдерживаемый формат → исключение ValueError
- Файл не найден → исключение FileNotFoundError
- Превышен размер файла → исключение FileTooLargeError

## Потребители
