## 2. Правка кода

- [x] 2.1 **[P]** `describe()` (`libs/vectors/owner.py`) отдаёт поле `enabled`
  отдельно от `declared`: объявленный и отключённый индекс — разные вещи, и без
  отдельного поля вызывающая сторона обязана считать отключённый неготовым.
- [x] 2.2 **[P]** `_prepare_capabilities` (`servers/enterprise/server.py`) берёт
  в прогрев только `enabled` индексы.
- [x] 2.3 **[A]** `gateway.py`: проверка готовности судит объявленные и
  включённые; незаявленные источники названы отдельной фразой; `_indexes_line`
  считает по тем же правилам и показывает отключённые отдельной частью строки.
- [x] 2.4 **[A]** Отсутствующие `declared` / `enabled` в ответе читаются как
  «объявлен и включён»: агент и платформа — разные процессы, при подъёме
  против старой сборки сервера полей ещё нет. Иначе сводка сказала бы
  «индексы не объявлены» при трёх готовых индексах.
- [x] 2.5 **[P/A]** Докстринги `owner.py`, `preload.py`, `docs/ARCHITECTURE.md`
  приведены в соответствие с кодом. **Именно эти докстринги были источником
  противоречия** (1.3).
