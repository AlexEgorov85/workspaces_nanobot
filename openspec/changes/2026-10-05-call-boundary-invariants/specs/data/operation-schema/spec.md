# Дельта: категория операции обязана совпадать с каталогом capability

## ADDED Requirements

### Requirement: Категория операции обязана совпадать с каталогом capability

`ToolDefinition.category` — это имя capability, а не свободная классификация.
Значение обязано совпадать с именем каталога, в котором лежит файл операции:
фильтрация при загрузке берёт capability из пути (`libs/enterprise_common/loader.py:73`),
а применение политики, журнала и артефактов — из объявления
(`registry.py:343-347`, `execution/policy.py:152`, `execution/pipeline.py:149`).

Пока обе стороны не сверены, файл может зарегистрироваться под чужой capability.
След у такого расхождения — только чужой журнал и чужие артефакты, поэтому оно
обнаруживается по косвенным признакам или не обнаруживается вовсе. Сегодня все
33 операции объявляют `category` значением, совпадающим с каталогом, то есть
правило соблюдается — но ничем не защищено.

#### Scenario: Категория совпадает с каталогом

- **WHEN** файл в `capabilities/audit/tools/generate_sql.py` объявляет
  `category="audit"`
- **THEN** операция SHALL загрузиться, зарегистрироваться и получать политику,
  журнал и артефакты capability `audit`

#### Scenario: Категория не совпадает с каталогом

- **WHEN** файл в `capabilities/data/tools/log_event.py` объявляет `category="audit"`
- **THEN** загрузка SHALL прерваться с `ToolLoadError`
- **AND** сообщение SHALL называть обе стороны расхождения: имя capability из
  пути и объявленную категорию
- **AND** операция SHALL НЕ попасть в реестр, потому что она способна увести
  журнал, артефакты и переопределение политики в чужую capability без следа

#### Scenario: Категория обязательна

- **WHEN** объявление `ToolDefinition` оставлено пустым
- **THEN** загрузка SHALL прерваться с `ToolLoadError`, как и до этого
- **AND** проверка непустоты в `registry.py:322-323` SHALL сохраниться, а не быть
  заменена сверкой с каталогом

#### Scenario: Сверка при фильтрации набора capability

- **WHEN** загрузка ограничена набором capability (например, `--capabilities data`)
- **THEN** имя для сравнения SHALL браться из каталога файла, а не из объявления,
  иначе расхождение может пройти как «файл не входит в фильтр»

#### Scenario: Строй против регрессии

- **WHEN** в тестовом дереве платформы добавлен файл операции с `category`,
  совпадающей с каталогом, и файл с `category` от чужой capability
- **THEN** первый SHALL загрузиться, второй SHALL быть отвергнут
- **AND** тест SHALL проверять оба случая, а не только успешный
