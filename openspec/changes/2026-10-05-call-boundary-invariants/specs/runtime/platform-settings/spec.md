# ДЕЛЬТА ПЕРЕМЕЩЕНА — файл подлежит удалению

Этот файл не содержит требований и **не должен попасть в архив**.

Требование о бюджете ожидания вызова переехало из `runtime/platform-settings` в
новую capability `runtime/call-timeout`
(`../call-timeout/spec.md`). Причина переезда, проверенная по коду:

- `openspec/specs/runtime/platform-settings/spec.md:40-41` в разделе
  `Does Not Own` прямо исключает «содержимое самих настроек» и отправляет его в
  `configuration/*` и `logging-db`;
- состав блока настроек — `lib/services/agent_settings.py:114-120`
  (`AGENT_BLOCK_PATHS`) — это только `logging.db.min_level` и
  `transport.{mode,bind,port,notify_fd}`; ни один таймаут туда не входит;
- на `runtime/platform-settings` уже висят две другие открытые дельты
  (`2026-10-04-enterprise-mcp-http-transport`, `implement-platform-settings-block`),
  и требование о сквозном бюджете вызова к этому capability отношения не имеет.

Оставленная здесь редакция требования была к тому же неверна: она требовала «не
меньше» бюджета платформы, а равенство бюджетов (`120.0` и `120.0`) пропускает
ровно то состояние, от которого инвариант защищает. Исправленная редакция —
«строго больше», с объявленным запасом — находится в
`../call-timeout/spec.md`.

**Действие для владельца:** удалить этот файл и пустой каталог
`specs/runtime/platform-settings/`. Удаление через `rm` на этой машине
заблокировано сбоем локального лаунчера (`mavis-trash` недоступен), а обходные
способы удаления запрещены политикой безопасности.
