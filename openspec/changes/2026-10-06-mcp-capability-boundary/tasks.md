# Задачи: граница MCP, capability вместо зеркала `DataService`

Порядок не по «логике проекта», а по тому, что какой шаг ломает. Раздел 1
обязателен для всего остального: без обязательной аудитории переименование
размножит объявления, у которых неизвестно, публикуются они или нет.

Разделы можно вести параллельно **только** с разными владельцами файлов.
`libs/enterprise_common/**`, `servers/enterprise/server.py`,
`libs/enterprise_common/settings.py` и `platform.json` трогает один исполнитель
одновременно: в них пересекаются правки 1, 3 и 4.
