# GitHub Release v2.5.1 — публикация

Этот документ содержит готовые материалы для публикации GitHub Release
для тега `v2.5.1` (PATCH поверх `v2.5.0`).

## Параметры Release

- **Тег:** `v2.5.1`
- **Заголовок:** `v2.5.1`
- **Режим публикации:** описание ниже
- **Файл body:** `docs/releases/v2.5.1.body.md`

## Способ 1: через `gh` CLI

```bash
gh release create v2.5.1 \
  --repo AlexEgorov85/workspaces_nanobot \
  --title "v2.5.1" \
  --notes-file docs/releases/v2.5.1.body.md
```

## Способ 2: через curl + GitHub API

```bash
# Требуется GITHUB_TOKEN с правами repo
BODY=$(cat docs/releases/v2.5.1.body.md | jq -Rs .)
curl -X POST \
  -H "Authorization: Bearer ${GITHUB_TOKEN}" \
  -H "Accept: application/vnd.github+json" \
  https://api.github.com/repos/AlexEgorov85/workspaces_nanobot/releases \
  -d "$(jq -nc --arg body "$BODY" \
        '{tag_name:"v2.5.1",name:"v2.5.1",body:$body,generate_release_notes:false}')"
```

## Способ 3: вручную через web

1. Открыть https://github.com/AlexEgorov85/workspaces_nanobot/releases/new
2. Выбрать тег `v2.5.1` (target: `release/v2.5`, commit `ecb1826`)
3. Заголовок: `v2.5.1`
4. Скопировать содержимое `docs/releases/v2.5.1.body.md` в поле описания
5. Опубликовать
